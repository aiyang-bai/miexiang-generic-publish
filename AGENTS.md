# Project boundaries

Maintain this independent single-artifact publisher only. Read MAINTENANCE.md and the private canonical .maintenance state before maintenance. Never reset owner changes. Runtime data, profiles, evidence and credentials are not public source. No proxy, DNS, services, global skills, other projects, paid APIs or GPU changes. No external posting, merging, public visibility changes or release without explicit task authorization.

Use the canonical repository common Git directory to find the shared .maintenance lock and registry across worktrees. Work only in a registered dedicated worktree/branch for scheduled changes. No real provider writes in tests or CI. Preserve V1 identity, byte readback, no-overwrite and redaction contracts. Respect the current model/router chosen by the Owner. An unchanged run is NO_CHANGE, not a reason to create a commit.
