# Source and review scope

The first OSS candidate extracts reviewed code and contract tests from predecessor commit `dbdbe87bc5f159f40b6539135bfbd13053895e99`. It starts fresh Git history; that history is not a complete authorship audit. Private filesystem paths, profiles, tokens, runtime reports, research archives, business assets and original task instructions are excluded. Exact blob-to-file mapping and private evidence remain with the maintainer.

The allowlist covers Python package sources, contract tests, one legacy verification helper, dependency/build definitions, rewritten docs, disabled synthetic examples, and minimal CI. No vendored SDK/library source is included. The predecessor had no public license in the selected tree. Commit author labels alone do not prove legal ownership. Owner confirmation of rights and the proposed copyright holder is required before applying the license and publishing.

Candidate changes: configurable external runtime roots; runtime-relative report paths; optional COS dependency set; no-account offline fixture; self-contained regression setup; synthetic test repository identities; packaging/installation checks; documentation and bounded maintenance tooling. Historical provider results are not attributed to this candidate. The legacy candidate-freeze helper retains its separate predecessor evidence contract and synthetic fixture tests; it is not evidence that this OSS version has passed real provider E2E.
